# 《等等再做》拖延症清除器 ｜ DO IT LATER

> 你清除的每一件事，都會長出更多事情。

一個單頁式互動網站。畫面持續生成各種「待辦事項」（便利貼、系統通知、行事曆、聊天訊息、郵件、彈窗、檔案、倒數計時），你用**滑鼠**或**鏡頭手勢**清除它們——但清得越快，系統生成得也越快。體驗在約 45–60 秒內由乾淨可控逐步走向混亂、壓迫，最後停下來顯示：

> 「你只是把拖延，變成了另一種忙碌。」

---

## 一、啟動方式

這是純前端網站，**不需要後端、資料庫或安裝任何套件**。

### 方法 A：直接開啟（僅滑鼠模式）
直接用瀏覽器開啟 `index.html` 即可遊玩滑鼠模式。
（注意：`file://` 開啟時，瀏覽器**不允許使用鏡頭**，手勢功能無法啟用。）

### 方法 B：本機伺服器（滑鼠 + 鏡頭手勢，建議）
鏡頭手勢需要在 `https://` 或 `localhost` 環境下才能取得鏡頭權限。任選一種啟動本機伺服器：

```bash
# Python 3
python3 -m http.server 8000

# 或 Node.js
npx serve .
```

接著在瀏覽器開啟 `http://localhost:8000`。

> **為什麼需要 localhost / HTTPS？**
> 瀏覽器基於安全性，只允許在「安全來源」（HTTPS 或 localhost）下使用 `getUserMedia` 取得鏡頭。直接用檔案路徑開啟會被擋下，此時網站會自動退回滑鼠模式。

建議使用**最新版 Chrome**。

---

## 二、操作方式

開始畫面提供三個入口：

| 按鈕 | 說明 |
|------|------|
| **開始整理** | 直接用滑鼠開始 |
| **開啟鏡頭** | 啟用鏡頭手勢（會先徵求權限，影像僅在本機處理） |
| **僅使用滑鼠** | 不使用鏡頭，完整滑鼠體驗 |

**滑鼠**：點擊待辦即清除；按住拖曳可連續掃除多件。
**手勢**（需鏡頭）：
- 指尖碰觸 → 清除單一事項
- 手掌快速橫移 → 掃除路徑上多件
- 握拳 → 壓縮一件
- 張開手掌 → 小範圍清除

右上角可隨時切換**音效**與**減少動態效果**；右下角鏡頭視窗可關閉。

> 若鏡頭載入失敗或長時間偵測不到手部，網站會自動提示並切換為滑鼠模式。**滑鼠模式可完全獨立運作。**

## 三、檔案結構

```
index.html            # 頁面結構與所有畫面狀態（開始 / 互動 / 結尾 / 休息）
css/
  styles.css          # 設計系統、各待辦樣式、壓力升高的視覺變化、響應式
js/
  config.js           # ★ 可調整參數：時間階段、生成速度、壓力、難度
  data.js             # ★ 待辦文字、緊急標籤、誘導文字、視窗種類（皆為陣列）
  audio.js            # Web Audio 即時合成音效（可關閉）
  items.js            # 建立各種待辦視窗的 DOM 與清除動畫
  engine.js           # 遊戲狀態、生成迴圈、階段、壓力值、最終狀態與統計
  gestures.js         # 鏡頭手部辨識（MediaPipe Hands）與失敗退回
  main.js             # 畫面切換、滑鼠/手勢互動串接、設定開關
README.md
```

### 想修改內容？
- **待辦文字**：`js/data.js` 的 `TODO_TEXTS` 陣列。
- **緊急標籤**：`js/data.js` 的 `URGENCY`。
- **生成速度 / 各階段時間 / 壓力**：`js/config.js`。
- **顏色與字體**：`css/styles.css` 最上方 `:root` 變數。

## 四、使用到的外部資源（CDN）

- **字體**：Google Fonts — Noto Sans TC / Noto Serif TC / Space Mono
- **手部辨識**：MediaPipe Hands + Camera Utils（`cdn.jsdelivr.net`，僅在點「開啟鏡頭」時才載入）

> 無網路時：字體會退回系統字體、鏡頭手勢無法使用，但**滑鼠模式仍可正常遊玩**（音效為本機即時合成，不需網路）。

---

## 五、隱私與使用安全

- 鏡頭影像**只在瀏覽器本機處理**，不上傳、不儲存、不傳送到任何伺服器。
- 開啟鏡頭前會明確告知用途。
- 提供「**減少動態效果**」選項，並避免高頻率閃爍。
- 提供「**關閉音效**」選項（預設開啟）。
- 文字與背景維持足夠對比度。

---

## 六、難度與情緒節奏

| 階段 | 時間 | 生成間隔 | 感受 |
|------|------|----------|------|
| 一 | 0–15s | 2–3 秒 | 乾淨、可控、任務較大 |
| 二 | 15–30s | 1–1.5 秒 | 開始重疊，出現「快做完了」等誘導文字 |
| 三 | 30–45s | 0.4–0.8 秒（依清除速度動態加快） | 抖動、錯誤視窗、明顯壓迫 |
| 結尾 | 45s+ | 停止生成 | 聲音突然靜止、畫面變暗，顯示核心訊息與統計 |

壓力值會依畫面待辦數量、生成速度與清除節奏上升，並驅動背景變暗、陰影變重、文字重影與輕微晃動。
